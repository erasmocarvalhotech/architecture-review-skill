# Architecture Review Skill

An AI skill for deep software architecture analysis of complex systems.

The skill helps AI act as a software architect by analyzing requirements, architectural decisions, trade-offs, risks, scalability, resilience, observability, maintainability, and long-term sustainability.

## Capabilities

- Architectural reviews of systems and solutions
- Requirements and constraint analysis
- Design decisions and trade-offs
- Patterns and anti-patterns
- Security, performance, and scalability analysis
- Resilience and observability
- Maintainability and architectural sustainability
- Technical risk identification and mitigation

## Review process

The skill follows a structured approach:

1. Understand the context
2. Map the current architecture
3. Identify risks and problems
4. Evaluate alternatives and trade-offs
5. Recommend a contextualized direction
6. Consider future evolution and change costs

## Installation

Copy the `SKILL.md` file into the skills directory supported by your AI tool or coding agent.

The exact installation path depends on the tool being used.

## Usage

Use the skill when you need an AI-assisted architectural review, for example:

- Reviewing a microservices architecture
- Evaluating synchronous vs. asynchronous communication
- Identifying architectural risks
- Analyzing scalability and resilience
- Evaluating patterns and anti-patterns
- Planning architectural modernization
- Reviewing technical trade-offs

## Response language

The skill responds in the user's language unless another language is explicitly requested.
